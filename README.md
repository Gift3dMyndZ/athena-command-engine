# Athena Command Intelligence Engine

Athena is a modern C++23 AI orchestration and intelligence service for the Joshua Wolfe Platform Engineering Command Center.

## Planned Capabilities

- REST API built with Drogon
- Local AI inference using llama.cpp
- Standardized REST error handling
- Request validation and request IDs
- Unit and integration testing
- GitHub repository intelligence
- Resume and career intelligence
- Health, readiness, and metrics endpoints
- React Command Center integration
- Containerized production deployment

## Technology Stack

- C++23
- CMake
- Drogon
- llama.cpp
- GoogleTest
- spdlog
- cpr
- React and TypeScript

The initial project structure and first C++ executable have been created.
